# Archived plans

Plans and notes from Orchestra 0.5.x and earlier: tmux sessions tied to git worktrees, the shell
services layer, merge helpers, env-copy and remote mode. All of these were removed by the sessions
refactor (`../sessions-refactor.md`), so these files describe behaviour that no longer exists. They
are kept for history only.

`spec_auth.md` still describes the auth module in `tui/src/auth`, which is switched off and
deferred to the next round (`../sessions-refactor.md` §18).
