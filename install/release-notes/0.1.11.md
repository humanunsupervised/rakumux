# Rakumux 0.1.11

## Agent statuses you can trust

- Subagents stay counted: a subagent's own tool hooks keep it alive, a parent's Stop no longer
  drops agents still running in the background, and activity stays fresh for 10 minutes while
  hook-reported subagents run.
- A Claude Code turn that ends while background agents work stays "working" (including its
  "Waiting for N background agents" screen).
- Claude's idle notice (about a minute after a reply) no longer turns a finished reply into
  "waiting for you"; `/compact` no longer leaves a session "working"; an API error
  (`StopFailure`) ends the turn; MCP questions show "waiting for you".
- Interrupting Claude with Esc ends the turn once its screen has looked idle for 5 seconds,
  instead of up to 2 minutes later.
- OpenCode V2 run as `opencode2` is recognised: its status, unread replies and worktree work,
  and reviving resumes it with `opencode2 -s <id>`.

## Subagent count

- Running subagents show as a count after the status in each session's description, the
  detail's title and Grid cards: `◈ 3` (🤖 or a Nerd Font robot with those icon sets).

## Footer and keys

- The footer names the session in its centre: `session: <name>` for the selected session in
  Rakumux mode, or the one taking your keys in session mode.
- `S` in Rakumux mode restarts the server in place with this build, after asking; sessions keep
  running. Settings has Restart UI and Restart server rows, the latter with the running
  server's version next to this build's.
- Esc (or the Rakumux key) with no session to go back to, as after a start or a UI reload,
  goes into the running session in view.

## Upgrading

The status fixes need the new server: after updating, press `S` (or run
`rakumux daemon restart`); running sessions keep running.

- Claude Code: merge the new `StopFailure`, `Elicitation` and `ElicitationResult` entries from
  `rakumux session hook-config --agent claude` into your settings.
- OpenCode: after the server restart, run `rakumux-mcp opencode-plugin --install`, then restart
  OpenCode.
- Codex hooks are unchanged; trust them in `/hooks` if you haven't.

See the
[integration setup instructions](https://github.com/humanunsupervised/rakumux/blob/main/integrations/README.md#setup).
