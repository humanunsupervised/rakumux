# Rakumux 0.1.58

## Heartbeats: tasks your agents run on a clock

- Rakumux can now run a task for you on a schedule: every N minutes, daily at a time, or on chosen
  weekdays at a time, in your local time. At each due time it starts a new session in the task's
  folder, starts its agent and types the task in once the agent is at its prompt.
- Press `B` for the drawer's new Beats tab, beside the Feed and rtop. `n` makes a heartbeat and opens
  your last agent in that folder to fill it in with you. `e` approves one, `p` pauses it, `r` runs it
  now, and Enter shows its command, task and runs.
- Runs are ordinary sessions, named like `nightly-deps #3` with `♥` before them. When a new run
  starts, earlier runs that are finished are ended (Enter resumes one). The last 10 stay listed, and
  older ones go to the session history.
- A new heartbeat's agent starts with the flags of the agent you last ran in that folder, so a
  heartbeat runs with the same permissions you use there.
- A heartbeat an agent makes or changes waits, paused, until you've read it and approved it. Agents
  can't enable, run or delete heartbeats.
- From the command line: `rakumux heartbeat ls | show | add | update | enable | pause | run | rm`,
  for example `rakumux heartbeat add deps --daily 09:00 -- "update dependencies and open a PR"`.
- Agents with the Rakumux MCP get `list_heartbeats`, `create_heartbeat` and `update_heartbeat`, and
  the local API has `/v1/heartbeats`.
- The machine has to be awake and running Rakumux at the due time. After a long sleep, a
  heartbeat runs once, not once for every time it missed.
