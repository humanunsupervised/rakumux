# Rakumux v0.1.1 — Linux binary release

The first published native binary release of Rakumux is available for **Linux x64**.
macOS packages are not included in this release.

```bash
curl -fsSL https://rakumux.com/install.sh | bash
```

The installer verifies the release checksum before installing the TUI/CLI, daemon, HTTP API
and MCP server. The Linux binaries use static musl linking. No npm or Homebrew setup is needed.

## Included improvements

- Full-colour live previews in Rakumux mode.
- Colour-coded app names before branches in session descriptions.
- New sessions follow the currently selected folder section.
- Both `d` and `dd` open delete confirmation.
- `R` asks before restarting the UI; the daemon and session programs keep running.
- Updated landing-page demo, user-only archive imports and safe folder-reference relocation.
- Root `release.sh` accepts one target or a comma-separated target list with `--targets`.

The failed, unpublished `v0.1.0` tag is preserved rather than overwritten. macOS verification
remains required when macOS targets are explicitly selected for a future release.

Rakumux's core is Apache-2.0. Every package includes `LICENSE` and `THIRD_PARTY_NOTICES`.
