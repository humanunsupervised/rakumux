# Rakumux 0.1.88

## Heartbeats agents set up run

- **No approval step.** A heartbeat an agent makes, from inside a session
  (`rakumux heartbeat add`) or through Rakumux's MCP tools (`create_heartbeat`), is on as soon as
  it has a prompt and a schedule. You no longer press `e` to approve it.
- **`Ask agent` finishes the job.** In the New heartbeat form, `Ask agent` has an agent set the
  heartbeat up. It turns on by itself once the agent saves the prompt and schedule. Until then
  Heartbeats marks it `◌ setting up`.
- **Changes keep it running.** An agent can change a heartbeat's prompt, schedule, agent or command
  (`rakumux heartbeat update`, `update_heartbeat`) and it keeps running. A heartbeat you paused
  stays paused.
- **Agents run any heartbeat.** `rakumux heartbeat run` and `run_heartbeat` start a run now,
  paused or not.
- Turning a heartbeat on, pausing it and deleting it are still yours, here or with `rakumux
  heartbeat enable|pause|rm`. From rakumux.com you can still only pause one.
