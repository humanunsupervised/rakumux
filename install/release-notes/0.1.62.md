# Rakumux 0.1.62

## Pair your devices, and your machine acts only on what they sign

- Pair a browser or the Rakumux app with a machine: `rakumux devices pair`, or Settings → Paired
  devices. It shows a one-time code, a link and a QR code. Open the link in the browser, or type
  the code in the app, then press `y` once the device's name and fingerprint match.
- Once a device is paired, that machine carries out replies, session messages, answers, new
  sessions, deletions, renames and updates from rakumux.com only when a paired device signed
  them. A paired browser signs as you send, with nothing to press: someone who gets into
  rakumux.com's database or steals a sign-in token can't make your machine act. Pausing a
  heartbeat stays as it is.
- `rakumux devices log` shows what became of each command: which device signed it, or why it
  was refused.
- A machine with no paired device works as before. `rakumux devices ls` lists the paired devices
  and `rakumux devices rm` forgets one.
- Replies you write in this machine's own feed still go in. Replies written in another
  machine's feed aren't signed, so a machine with paired devices refuses them.
