# Rakumux 0.1.8

## Agent activity badges

- Session items show a larger, padded activity badge immediately before the time.
- An animated spinner means the agent is working, including active subagents.
- A hollow dot means idle; a filled dot means an unread completed reply.
- Waiting for input or permission keeps its distinct attention marker.
- Opening a session clears unread across windows. Passive list and Grid previews do not.
- Replies arriving in the foreground open conversation are marked seen automatically.

## Reliable completion tracking

- OpenCode reports completion identifiers so repeated snapshots cannot make an opened reply unread again.
- Duplicate Claude Code and Codex completion hooks do not resurrect a seen reply.
- Switching OpenCode conversations does not transfer the previous conversation's unread state.
- Compatible in-place daemon restarts preserve acknowledgements of hook-reported completions.

Agent integrations remain opt-in, with terminal detection as the fallback. See the
[integration setup instructions](https://github.com/humanunsupervised/rakumux/blob/main/integrations/README.md#setup).
To update the OpenCode plugin, run `rakumux-mcp opencode-plugin --install`, then restart OpenCode.
