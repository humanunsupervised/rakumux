# Rakumux v0.1.5 - session activity at a glance

- Optional AI activity summaries add a third line under each session. Full text, age and
  refresh errors appear above the preview in Rakumux mode.
- Each session update resets a 10-second idle timer. Unchanged output is not sent again;
  existing live, exited and dead sessions are backfilled from available output without
  recreating their terminals.
- Bring your own Anthropic or OpenAI API key in Settings, General, AI. No key is included in
  the binaries. Keys are stored locally with owner-only permissions, masked in the UI and
  excluded from input-debug logs.
- Summaries are off by default and require consent to share bounded output with your provider.
  Private sessions are excluded; secret filtering is best-effort, not a guarantee. Provider
  requests may incur charges.
- New session now creates a generated-name session immediately and enters its login-shell
  prompt without a naming dialog. Use `r` in Rakumux mode to rename it afterwards.
- The title, terminal preview and activity summary share the same subtle inactive styling
  in Rakumux mode. Active session mode and the session list remain unchanged.

After upgrading, reload the TUI and use `rakumux daemon restart` to load the daemon features
in place while keeping running programs. Then add your API key and enable Activity summaries
in Settings. In-flight provider requests may finish after summaries are disabled.
