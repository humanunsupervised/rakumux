# Rakumux v0.1.5 - live Grid view and in-app updates

- New session creates a generated-name session immediately and enters its login-shell
  prompt without a naming dialog. Use `r` in Rakumux mode to rename it afterwards.
- `v` cycles Master detail (the default), Grid and Tabs. Grid shows paged, live terminal
  previews without taking control or resizing sessions. Enter or a tap opens a session;
  `Ctrl-\` returns to Grid. Folder/text filters and saved output are supported.
- Inactive session titles and previews fade by 30%, and by 45% under dialogs or for saved
  output. Active terminal output and the session list are not faded.
- Session titles have stronger bold/bright emphasis. App-name labels use quieter Tokyo Night
  blues so the title leads; terminal font size remains controlled by the terminal app.
- Credential dialogs are excluded from input-debug logs, and configuration files are saved
  atomically with owner-only permissions.
- `Shift+U` or Settings → General → Update checks for a release, asks before installation,
  verifies binary release checksums/versions, and restarts only the UI. Sessions keep running.
  Source builds and admin-owned installs show manual instructions. Cached availability no
  longer installs anything automatically at startup.
- Opt-in OpenCode, Claude Code and Codex hooks report activity phases and active subagent
  counts. Busy markers animate locally; input requests and done remain static. Agent-specific
  runtime code lives under `Integrations/`. These hooks make no AI requests.

Activity hooks are an initial, opt-in integration. Real-agent version coverage is incomplete;
screen/process detection remains the fallback. See `Integrations/README.md` for setup and limits.

Local AI activity summaries are not included. Their implementation is deferred while a
standalone-server design is planned. The pre-existing optional AI naming feature is unchanged.
