# Rakumux v0.1.5 - immediate session creation

- New session creates a generated-name session immediately and enters its login-shell
  prompt without a naming dialog. Use `r` in Rakumux mode to rename it afterwards.
- Session titles and terminal previews use consistent subtle inactive styling in Rakumux
  mode. Active session mode and the session list remain unchanged.
- Credential dialogs are excluded from input-debug logs, and configuration files are saved
  atomically with owner-only permissions.

Local AI activity summaries are not included. Their implementation is deferred while a
standalone-server design is planned. The pre-existing optional AI naming feature is unchanged.
