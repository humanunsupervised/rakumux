# Rakumux 0.1.64

## Nothing unsigned from rakumux.com or the app

- Your machine now carries out a reply, new session, deletion, rename or heartbeat pause from
  rakumux.com or the app only when a browser or phone you paired with it signed it. Until you pair
  one, nothing asked there is carried out. Replies written in this machine's own TUI still go in.
- A reply written in another machine's TUI can't be signed, so it's refused.

## Pair a device with one key

- Press `D` in the session list to pair a browser or phone with this machine: the code, its link
  and QR code show at once, as `rakumux devices pair` does. Settings lists it with the other keys.
