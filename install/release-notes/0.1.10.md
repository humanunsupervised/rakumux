# Rakumux 0.1.10

## Session list tabs

- The list's top row has three tabs: **Status**, **Folders** and **App**. The active tab groups
  the list (a header per status, folder or app) and has its own filter: Enter (or a click on the
  active tab) opens a dropdown where you pick one or tick several.
- Status sections put what needs you first: waiting for you, done, working, waiting for
  response, running, exited, dead, then idle.
- App sections follow the agent (claude, codex, opencode, …), else the running program, else
  shell.
- `←`/`→` on the top row switch tabs; `P` still opens the folders dropdown.
- The list is wider by default, the activity mark follows the time, and unselected sessions
  are quieter so the selected one stands out.

## Settings

- One scrolling page instead of tabs: the settings, then every action with its keys (Enter
  runs it). It's sized to its rows, up to 80% of the screen, with values pinned to the right.
- `→` shows what the selected row does in a popover; the page never shifts. The mouse wheel
  moves through it.
- The phone access and AI naming rows are gone. Use `rakumux remote on|off|pair` for phone
  access; AI naming reads its keys from `~/.rakumux/config.json` or `ANTHROPIC_API_KEY` /
  `OPENAI_API_KEY`.

## Footer and colours

- The footer is a full-width bar: orange in Rakumux mode with `| session: <name>` and `? Help`
  / `, Settings` buttons, muted blue in session mode with a `Ctrl-\ Rakumux` button. All of them
  are clickable.
- Programs in the detail, Grid cards and the terminal panel keep your terminal's own colours
  instead of the Rakumux theme.

## Behaviour

- Ending the program you're working in (`exit`, Ctrl-D, quitting the agent) deletes its
  session. A session that ends in the background stays, its last screen kept for a restart.
- Esc is instant on a local terminal (25 ms). Over SSH it still waits for split arrow keys:
  300 ms in sessions and dialogs, 800 ms in Rakumux mode's list.
- Every start opens Master detail; the layout you switch to isn't saved any more.
- Phones offer Master detail and Tabs (now with its tab bar in Rakumux mode too), not Grid.

## Upgrading

Only the UI changed. `U` (or Settings → Update) installs it and reloads the UI; the daemon and
running sessions stay up.
