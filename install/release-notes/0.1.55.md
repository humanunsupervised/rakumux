# Rakumux 0.1.55

## Sessions from your phone

- A session can be deleted from rakumux.com and the mobile app: swipe its row left, then tap Delete.
  It ends on its machine and stays in that machine's session history for 90 days.

## Answering agents' questions

- Claude Code's tabbed questions can now be answered from rakumux.com and the mobile app when the
  dialog is taller than the terminal, as long questions on a phone-sized terminal are.
