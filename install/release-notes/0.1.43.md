# Rakumux 0.1.43

## Installing and updating

- `curl -fsSL https://rakumux.com/install.sh | bash` now installs where Rakumux can update
  itself: into `/usr/local` when you can write there without `sudo`, otherwise into `~/.local`
  (it tells you when `~/.local/bin` isn't on your `PATH` yet). Run it again and it updates the
  copy it installed.
- An install Rakumux can't write to (one the installer put in a root-owned `/usr/local`)
  couldn't update itself. Rakumux now says how to fix that: run the installer again, which moves
  it to `~/.local` and tells you how to remove the old copy.

## Under the hood

- Dependency updates: `bytes` 1.12.1, and the standard library's terminal check in place of the
  unmaintained `atty`.
