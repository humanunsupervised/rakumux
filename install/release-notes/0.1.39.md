# Rakumux 0.1.39

## Answer GitHub Copilot's and Droid's questions from rakumux.com

- When GitHub Copilot or Droid asks you something in its question dialog, its chat on rakumux.com
  lets you answer it, as you already can for Claude Code: pick an option, tick several, or type your
  own answer. After updating, press `S` so the server can answer them.

## Fixes

- A message from rakumux.com to an agent that had only just started (a new session started on the
  web, say) could be typed before the agent was ready, and lost. Rakumux now waits until the
  agent's prompt is on screen.
- Such a message no longer shows as delivered unless the agent's chat shows it as your prompt. When
  it doesn't, it's reported as not taken, and ↻ on rakumux.com sends it again.
