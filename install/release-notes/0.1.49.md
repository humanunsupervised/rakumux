# Rakumux 0.1.49

## Session list

- A session's last line shows its app, its subagents and its report again, as before 0.1.48. An
  ended session again says `exited · ⏎ restart` or `dead · ⏎ revive`.
- The Folders tab is now **Repos**: a section per repository, named by its `origin`, with
  worktrees and branches under their repository. The App tab is now **Agent**.
- Each section's header is a bar in a colour of its own. Click it, or press Space on it, to
  collapse its sessions; do it again to show them.
- A new session is named `New session` (`New session 2`, … in the same folder) until its AI
  title or you name it.

## AI titles

- A coding agent's session is titled as soon as you give the agent its first prompt, from that
  prompt.
- Any other program is titled a second after it starts, from the command that started it, instead
  of after 5 seconds.

## Updates

- A new release opens a window with what's new: **Update now** installs it and restarts
  Rakumux in one go (the window, the server and its services; sessions keep running), **Later**
  leaves it until the next release. With automatic updates on, it installs by itself and the
  window offers **Restart now**.
- Signed in, you hear of a release as soon as it's published; Rakumux also checks every hour
  instead of every day.
- rakumux.com and the Rakumux app can update your machines: each machine running this release
  can be told to install a newer one and restart in place, and says how it went.
- Updating to this release still needs one `S` afterwards; from the next one, an update restarts
  everything by itself.
