# Rakumux 0.1.83

## Every run of a heartbeat

- **Each heartbeat keeps a record of its runs.** Every time it's due and every run you start, with
  when it ran and what became of it: working, done, ended, or skipped or failed and why. Runs
  already listed start the record.
- **Watch a run.** `Enter` on a heartbeat shows its runs, newest first. The session pane shows the
  selected one: live while it runs, its final screen once it ended. `↑` `↓` pick another, `Enter`
  goes into it.
- **Older runs stay readable.** Only the newest 10 runs stay in the session list. Older ones move to
  the session history but stay listed, and their saved output still shows. `Enter` brings one back.
- `rakumux heartbeat runs <name>` lists them (`--json` for scripts and agents).
