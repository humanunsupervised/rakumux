# Rakumux 0.1.9

## Standalone terminal panel

- `T` opens a temporary shell below the main detail, in the selected session's current
  directory (or the current folder). It is no longer a Rakumux session: nothing is added to the
  session list, saved or revived.
- Hiding the panel keeps its shell and running command; reopening shows the same terminal.
- Typing `exit` (or end-of-file) closes the pane and releases its terminal, even while hidden.
- Closing or reloading the UI ends only that temporary shell, never any Rakumux sessions.
- A daemon restart in place keeps the pane; it reconnects read-only until you focus it again.

## Branch labels follow the agent

- With agent integrations enabled, a session's branch and worktree follow the coding agent's
  active or last-used worktree while that agent runs, instead of the terminal's launch folder.
- OpenCode reports the displayed conversation's directory, Claude Code and Codex their root
  hook `cwd` (Claude's new `CwdChanged` hook keeps it current). Subagents, tool arguments and
  transcripts are never used.
- Without an agent, the label follows the terminal's current directory, now also when the
  terminal is quiet. The session's folder and permissions never change.

## Upgrading

Both features need the new daemon. After updating, Rakumux offers to restart it in place;
running sessions keep running. Or run `rakumux daemon restart`.

Existing Claude Code and Codex hooks report worktrees without changes. To follow Claude's
directory changes between prompts, merge the new `CwdChanged` entry from
`rakumux session hook-config --agent claude`. Update the OpenCode plugin with
`rakumux-mcp opencode-plugin --install`, then restart OpenCode. See the
[integration setup instructions](https://github.com/humanunsupervised/rakumux/blob/main/integrations/README.md#setup).
