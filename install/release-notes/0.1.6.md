# Rakumux v0.1.6 - live Grid view and in-app updates

Available for macOS Apple Silicon, macOS Intel and Linux x64. The `v0.1.5` tag was not
published as a release because its Linux static build failed; this release includes that fix.

- `v` cycles Master detail (the default), Grid and Tabs. Grid shows paged, live terminal
  previews without taking control or resizing sessions. Enter or a tap opens a session;
  `Ctrl-\` returns to Grid. Folder/text filters and saved output are supported.
- New sessions open immediately at a generated-name login-shell prompt, without a naming
  dialog. Use `r` in Rakumux mode to rename one.
- Busy session items show an animated spinner, including in Grid. Inactive previews fade by
  30%, or 45% under dialogs/for saved output. Titles are bolder and app labels use muted blues.
- `Shift+U` or Settings → General → Update checks for a release, asks before installation,
  verifies binary checksums/versions, and restarts only the UI. Sessions keep running. Source
  builds and admin-owned installs show manual instructions; startup never installs implicitly.
- The Linux updater uses the atomic-exchange syscall directly so static musl builds work with
  the pinned libc. CI now builds the static target and runs its updater regression tests.
- Agent-specific code lives in `integrations/open-code`, `integrations/claude-code` and
  `integrations/codex`. Opt-in hooks share activity phases and subagent counts without AI calls.
- Credential dialogs are excluded from debug input logs. Configuration saves are atomic and
  owner-only.

Activity hooks are an initial opt-in integration; real-agent version coverage is incomplete.
Screen/process detection remains the fallback. See `integrations/README.md` for setup and limits.
Local AI activity summaries are not included. Pre-existing optional AI naming is unchanged.
