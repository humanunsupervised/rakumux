# Rakumux 0.1.71

## Machines no longer come back to rakumux.com all at once

- When rakumux.com restarts or has a hiccup, every machine used to retry on the same schedule and
  reconnect in the same second. Each machine now waits a little longer at random (never less than
  rakumux.com asks), so they come back spread out and a busy moment passes instead of repeating.
- Nothing changes in what you see: replies, the Inbox and sessions work as before.
