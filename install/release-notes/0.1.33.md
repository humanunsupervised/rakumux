# Rakumux 0.1.33

## Signed in, everything is on

- AI session titles, the Agent feed, replies and new sessions from rakumux.com, and rtop on
  rakumux.com are on for every signed-in account, Free or Pro. Settings has no switches for them
  any more, and rakumux.com has no Features page. Pro keeps 90 days of history instead of 7.
- Signing out (`rakumux account logout`) is what stops rakumux.com reaching this machine's
  sessions. Private sessions are never sent.
- `rakumux sprite connect` no longer asks about replies; `--replies` and `--no-replies` still work
  and do nothing.

## rtop in the drawer

- `t` opens rtop in the drawer on the right, beside the Feed: what this machine, Rakumux and each
  session's processes use now.
- On rakumux.com, rtop shows the same for each of your machines while you have it open.

## New sessions from rakumux.com

- **+ New session** at the foot of each folder on rakumux.com starts a shell, Claude Code, Codex or
  OpenCode there on that machine, with a first prompt if you like. Only in a folder the machine
  already lists; never a path or a command from the website.

## AI titles

- A chat's title comes from your latest prompt and what the agent wrote since, never from an
  earlier turn.
- Restarting the account service or the server no longer titles chats again that already have
  their title.

## The session list

- The place a session works in now ends with how many places it has changed files in; `w` lists
  them.

## Upgrading

`U` installs the update and reloads the UI, and the account service replaces itself with the new
version. Press `S` to restart the server in place (sessions keep running) for titles from the
latest prompt. For your Sprite, run `rakumux sprite connect` again to update Rakumux there.
