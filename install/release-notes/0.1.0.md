# Rakumux 0.1.0

Rakumux's first public release: persistent terminal sessions for coding agents, with an
Apache-2.0 open-source core.

## Highlights

- Run Claude Code, Codex, OpenCode, Pi, shells, and dev servers side by side.
- Keep sessions running when the UI closes or an SSH connection drops.
- Browse live previews across folders; filter, rename, reorder, and pin sessions.
- Switch between your program and Rakumux with `Ctrl-\`.
- Use the CLI, local HTTP API, or MCP server for automation and coding-agent integration.
- Restart the daemon in place without stopping running programs. Recover interrupted sessions
  after a crash or reboot using supported agents' resume commands.
- Enable optional Tailscale remote access and pair a separately maintained mobile client.
- Generate session names with your own Anthropic or OpenAI key (optional).

## Installation

After release assets are published:

```bash
curl -fsSL https://rakumux.com/install.sh | bash
```

The installer checks the downloaded archive against the release's checksums before installing.
Prebuilt packages target macOS Apple Silicon, macOS Intel, and Linux x64. Bash is the only
additional runtime dependency; Git and tmux are not required.

Source and build instructions: <https://github.com/humanunsupervised/rakumux>.
Sessions and settings are stored in `~/.rakumux`; `RAKUMUX_HOME` selects an isolated data directory.
