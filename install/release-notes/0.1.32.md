# Rakumux 0.1.32

## Your first Sprite session

- A folder's first session on your Sprite starts in the Sprite's home, with nothing made there,
  and the clone typed for you: for a GitHub repository, Enter signs in to GitHub if needed and
  clones it into `~/<folder>` (a new Sprite has no SSH key). Its next sessions start in the clone.
- When your Sprite is set up, Rakumux shows what's there and what's left to do.
- A folder with `.env` files is asked about once: say yes and they're copied to your Sprite and
  unpacked into the clone, never over a file it has.
- New Sprites are named `my-sprite`.
- On a Mac, Rakumux finds the `sprite` command's token in your keychain, so there's nothing to
  paste.

## Upgrading

`U` installs the update and reloads the UI; `S` restarts the server so new sessions on your
Sprite start in its home.
