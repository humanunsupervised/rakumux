# Rakumux 0.1.59

## Answer Claude Code's prompts from anywhere

- Claude Code's permission prompts ("Do you want to proceed?", an edit to make, a file to
  create) and its plan approval can be answered on rakumux.com and in the mobile app. Your
  machine reads the prompt off the session's screen. When you pick an option, it presses that
  option's number, and only while the session still shows that exact prompt.
- A session whose permission prompt you answered in the terminal, including with No or Esc,
  stops showing as waiting for you right away, instead of up to two minutes later.
