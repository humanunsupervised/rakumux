# Rakumux 0.1.13

## Sign in for AI session descriptions

- Settings → Account signs in to your Rakumux account: approve the code it shows in any
  browser, with the link or its QR code. `rakumux account login` does the same from a shell.
  Accounts are by invitation for now: join the waitlist at <https://rakumux.com>.
- Signed in, each session in the list gets a very short AI description under its name, of what
  it's doing or needs. It's written again when an agent finishes a reply, and at most once a
  minute otherwise.
- To write them, the recent terminal output and agent reports of your live sessions go to
  rakumux.com, with the secrets it recognises removed first. Private sessions are never sent.
  AI session summaries are on by default: turn them off at <https://rakumux.com/features>, and
  sending stops within about two minutes. `rakumux account logout` signs this machine out. See
  <https://rakumux.com/privacy>.
- `rakumux account status` shows who is signed in, whether summaries are on, and each described
  session.

## The list

- Rakumux opens on the Status tab.
- Unread is a reply you haven't looked at yet; Done is one you've read. Done sessions are listed
  by when you last read them, under last hour, last day and older.
- The detail has no title row: the footer names the session in view, with its status mark.
- Rows no longer repeat the status in words; the mark on the right says it.
- A lone folder shows its header, and worktrees get sections of their own.

## Upgrading

Only the UI changed. `U` (or Settings → Update) installs it and reloads the UI; the server and
running sessions stay up. Signing in starts a small background service for your account
(`rakumux status-service`), which keeps running like the server.
