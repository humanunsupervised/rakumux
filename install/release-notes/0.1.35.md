# Rakumux 0.1.35

## Subagents on rakumux.com

- A chat on rakumux.com now shows the subagents its agent started (Claude Code's `Agent`,
  OpenCode's and GitHub Copilot's `task`), each under the call that started it, with what it was
  asked and what it did.

## Signing out

- Signing out (`rakumux account logout`, or Settings → Account) now also ends the sign-in at
  Clerk, so a copy of it left on the machine no longer works. If Clerk can't be reached, the
  machine is still signed out and Rakumux says so.
- **Sign out all terminals** on rakumux.com's Account page ends every machine's sign-in; each
  machine signs itself out the next time it checks in.

## Fixes

- A reply from rakumux.com no longer goes into a question Claude Code asks (AskUserQuestion)
  that stayed open for more than two minutes. A question or a prompt for permission an agent's
  hooks report now holds replies until its conversation moves on (an answer or an Esc), however
  long it waits.
- After `U`, replies no longer go into an agent at work while the server still runs the older
  version, which can't hold back the Enter if a permission prompt opens as a reply goes in. They
  wait until the agent stops, and Rakumux offers to restart the server in place (`S`); after
  that, replies go in while agents work again.
- Control characters in a folder's, branch's or worktree's name, or in what a session reports,
  show as `?` in the TUI and in `rakumux ls`; they never reach your terminal.
- A `.git` that is a pipe or a device, or belongs to another user, no longer stops the server
  answering. It's ignored, as git ignores it.
