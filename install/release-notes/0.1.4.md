# Rakumux v0.1.4 - subtle session previews

- Live session previews and their title rows fade lightly while browsing sessions in Rakumux
  mode, making it clear that keys go to Rakumux rather than the program.
- The preview fade reduces contrast by 12%, keeping output readable and colourful. Entering
  session mode restores the program's original colours immediately.
- The session list is unchanged. Dialogs and saved output retain their stronger fade.
- The public installer fixes Apple's Bash 3.2 UTF-8 variable-parsing error and is verified on
  native Intel and Apple Silicon Macs through the piped installation path.

Native packages for macOS Intel, macOS Apple Silicon and Linux x64:

```bash
curl -fsSL https://rakumux.com/install.sh | bash
```

Re-run the installer to upgrade, then restart the TUI to see the preview styling. Existing
sessions do not need to be stopped or revived.
