# Rakumux 0.1.36

- On a Mac, Rakumux could look for its server in another user's folder when two of its parts
  asked at the same moment, and fail to connect. It now asks the system who you are.

## Docs

- The docs moved to [docs.rakumux.com](https://docs.rakumux.com). Links to rakumux.com/docs still
  work: they go to the same page there.
