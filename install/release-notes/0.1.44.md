# Rakumux 0.1.44

## Fixes

- Agents' hooks failed with `rakumux.sh: not found` after you removed the install that started
  the server (switching from npm to the curl installer, say). The server kept handing new
  sessions that install's path; it now gives them the one Rakumux you started them from while
  its own is gone. Sessions started before the update keep the old path until restarted.
