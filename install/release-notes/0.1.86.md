# Rakumux 0.1.86

## Long prompts in Heartbeats

- **A prompt as long as you need.** The prompt in the New heartbeat form (`n`) and when you edit
  one (`c`) grows with its text while the window has room, then scrolls. The cursor stays in view
  as you type or move: `↑` `↓`, `PgUp` `PgDn` a page, `Home` `End` the start and end. The wheel
  scrolls it too, and a scrollbar shows where you are.
- **Paste it.** A pasted prompt keeps its lines, however many. `Ctrl-S` still saves from any field.
- **Read it whole.** `Enter` on a heartbeat shows its whole prompt. A long one scrolls with `PgUp`
  `PgDn` and the wheel.

## Agents run the heartbeats you approved

- **Run one now from a session.** An agent in a session can start a heartbeat's run now, as you
  can: with `rakumux heartbeat run` or the MCP tool `run_heartbeat`. The run is a new session,
  recorded with the heartbeat's other runs, whether the heartbeat is paused or not.
- **Only one you approved.** A heartbeat an agent made or changed waits for your approval, and no
  agent can run it until you approve it (`e` on Heartbeats, or `rakumux heartbeat enable <id>`).
  The refusal names that command.
- Approving, pausing and deleting heartbeats stay yours.
