# Rakumux 0.1.40

## Answer more agents' questions from rakumux.com

- OpenCode, Grok and Kimi Code questions can now be answered from their session's chat on
  rakumux.com, as Claude Code's, GitHub Copilot's and Droid's already can.
- Each machine now says which agents' questions it can answer. Machines on 0.1.39 show Copilot's
  and Droid's questions without the option to answer until they update. After updating, press `S`.

## Terminal panel beside the session

- `|` opens the terminal panel beside the session, `-` opens it below, and `T` opens it wherever
  you last had it. Beside needs a window about 150 columns wide with the list showing; narrower
  ones show it below. The placement is also in Settings.

## Tips in the footer

- The footer shows a tip of the day at the right, for a key or feature that's easy to miss. Click
  it for the next one, or turn tips off in Settings → "Tips in the footer".

## Waiting for you is marked ?

- A session whose agent is waiting for you (a question, a permission prompt or a menu) is marked
  `?` in the list, its tab, the footer and Grid.
