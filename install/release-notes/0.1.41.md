# Rakumux 0.1.41

## Signed releases

- Every release is now signed on the maintainer's computer, with a key that never lives in
  GitHub. Rakumux's updater installs a release only when its signature is valid for that
  version, and `install.sh` checks it too when `minisign` (or OpenSSL 3) is installed:
  `brew install minisign` on a Mac. A release without a valid signature is refused, and nothing
  changes.

## Automatic updates

- Rakumux now updates itself: a new release installs in the background, and each window reloads
  into it once you've left it alone for a minute in Rakumux mode. Sessions, the server and the
  API keep running. Only signed releases install this way. Turn it off in Settings → Update
  automatically; `U` still updates by hand.
- npm, Homebrew and source builds aren't updated for you: Rakumux tells you once when a release
  is out and how to get it.
