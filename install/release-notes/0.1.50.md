# Rakumux 0.1.50

## Session list

- A worktree removed from disk (once its branch is merged, say) leaves every session's places
  within a minute, ended sessions' too.

## AI titles

- Each new chat with a coding agent titles its session from the chat's first prompt, replacing
  the AI title the session had. A name you gave the session stays.

## Pinned sessions

- Pinned moved from the list's tabs to the drawer on the right, as its first tab before the Feed
  and rtop. Press `*` to show it. Moving through it previews each session, `Enter` goes in, `p`
  unpins and `J`/`K` or a drag orders them. Your saved order carries over.
