# Rakumux 0.1.21

## Message any session from rakumux.com

- On rakumux.com you can now write to a session that has nothing to reply to yet: a new chat, or
  one whose newest answer is in another chat. Rakumux types it in once an agent runs there and
  waits for you, and the agent's answer starts a new turn in your feed.

## Every program on the App page

- rakumux.com's App page groups sessions without an agent by the program they run, as the TUI's
  App tab does. Rakumux sends the program's name, never a path, and never for a shell.

## Follow your agents live on rakumux.com

- While you have rakumux.com open, Rakumux uploads an agent's chat every second instead of every
  5 seconds, so the website shows each step moments after the agent takes it.

## Replies wait while you type

- A reply written on rakumux.com is no longer typed into a session while someone is typing in it
  (in the last 10 seconds), so it isn't added to what you're writing. Text left unsent in the
  agent's prompt is still sent along with it.
- Two replies waiting for the same session now go in one turn at a time; before, both could be
  typed at once.

## A README for new users

- The README now walks through installing, the first session, the keys, the optional account and
  building from source.

## Upgrading

`U` installs the update and reloads the UI, and the AI status service replaces itself with the
new version. Replies waiting while you type also needs the new server: press `S` in Rakumux mode
(or run `rakumux daemon restart`) to restart it in place. Your sessions keep running.
