# Rakumux v0.1.7 - independent terminal and UI fixes

- `T` in Rakumux mode or Settings → General → Terminal panel opens an independent shell
  underneath the main detail, starting in the selected folder.
- The shell has its own keyboard/paste/mouse focus and a TERMINAL badge. Click a pane to focus
  it. The Rakumux key returns to Rakumux mode; Esc returns to the shell, and T or × hides it.
- Hiding only detaches the view: running commands keep running in a normal daemon session.
  This window reuses its shell per folder. Session records remain available after UI restart.
- Drag the horizontal divider to resize. Short windows show the focused pane alone. Browsing
  the shell does not send input or size claims to the agent above it.
- Reconnects preserve the shell record and resume read-only until refocused. Stale requests,
  other-client control, saved/exited screens and input-debug privacy are covered by tests.
- Settings hugs its General/Keys table instead of stretching across the screen. Notes wrap
  and narrow screens stay bounded; Help retains its documentation reading width.
- Rakumux mode uses a full-width orange footer with readable dark text. Dialogs keep it
  visible, while session and terminal input modes retain their quieter backgrounds.
- Clicking + New session creates and focuses the shell immediately on desktop as well as
  phones. The current folder is preserved, and pending creation ignores repeated clicks.

Updating reloads only the UI. Running sessions stay up; no daemon restart is required.
