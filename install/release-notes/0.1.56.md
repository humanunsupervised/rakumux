# Rakumux 0.1.56

## Drive your agents with the Rakumux MCP

- One coding agent can now drive the agents in your other sessions. Add the Rakumux MCP to it
  (`claude mcp add --scope user rakumux -- rakumux-mcp`), then ask it, for example, to have the
  Codex session in `api/` fix a flaky test and review the diff.
- New tools: `send_prompt` types a prompt or a command and presses Enter, `send_keys` presses keys,
  `wait_for_session` waits until an agent finishes or asks something, and `kill_session` and
  `revive_session` end or restart a session.
- `send_prompt` never types into a permission prompt, a question or a menu, and never over what
  you're typing. An agent can't drive its own session.
- An agent in a session now sees every folder's sessions and can drive or start sessions in any
  folder. Deleting sessions and managing folders stay yours.
- The local API has matching routes: `POST /v1/sessions/{id}/submit`, `/input` and `/wait`.
