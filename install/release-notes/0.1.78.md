# Rakumux 0.1.78

## A menu for workspaces

- The left column's Workspaces tab names the workspace you're in (`▴ Workspaces · Launch`). Click or
  tap it, or press `m`, and a menu opens over it with one row per workspace, the current one ticked.
  Picking one switches the sessions listed.
- The menu replaces the row of workspace buttons. New, rename (`e`) and delete (`d` twice) are in it.
