# Rakumux 0.1.70

## The feed is now the Inbox

- What your agents said, from every signed-in machine, is now called the **Inbox**: the footer's
  `f ≡ Inbox` button, the drawer's Inbox tab, Help, Settings and the messages about it. `f` still
  shows it.
- On rakumux.com it lives at [rakumux.com/inbox](https://rakumux.com/inbox); old links to
  `/feed` still work. The app calls it Inbox too.
- Nothing else changes: `rakumux account status --json` still says `feed`, and older releases keep
  working with rakumux.com.
