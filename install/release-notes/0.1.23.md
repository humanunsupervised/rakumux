# Rakumux 0.1.23

## The Feed beside your sessions

- The Feed is now a pane beside the session instead of a view in place of the list. It's hidden
  when Rakumux starts and opens only when you ask: press `f`, or the footer's `≡ Feed` button.
  Press `f` again while it has the keys to hide it; `Esc` gives the keys back to the list.
- Drag the line on its left to resize it. It needs room beside the session, so `b` (hiding the
  list) makes some. In a narrower window it takes the session's place in Rakumux mode only, so the
  session you're typing in keeps its full width.
- Grid shows it beside the cards, Tabs gives it a Feed tab at the start of the tab bar, and on a
  phone it fills the screen.
- `Enter` reads a reply whole, and `Enter` again goes into its session when it runs here.

## Write to an agent that's still working

- A prompt still waiting for its answer (a `working` card) can be answered now: `r` writes back on
  a session's newest card, whatever it is. Your message joins its chat's thread, or, when the
  chat has nothing to reply to yet, goes to the session itself, as it does on rakumux.com.

## Messages from rakumux.com, one at a time

- Two messages sent to a session close together could reach its agent as one prompt. Rakumux now
  types them one at a time, in the order you sent them, and waits for the agent to take each one
  before typing the next.
- The Enter now goes in on its own, half a second after the text. Claude Code dropped an Enter
  that came with a message ending in an image's path, so a message with an image attached stayed
  in its prompt and went with the next one.

## Where each session has worked

- Each session in the list shows the folder it works in now and its branch, and follows its agent
  into a worktree.
- When its agent has changed files in other git working trees too, `▸` beside it opens them:
  press `w` (`W` for every session) or click it. Each shows its path, its branch and when, most
  recent first. Folders it only started in or read from aren't listed.
- `y`, or a click on a place, copies its path. While they're open, `↓`/`↑` step through them.
- Places are read on this machine from what the agent did. With the Agent feed on, rakumux.com gets
  their names within the session's folder and their branches, never full paths.

## The footer

- The footer names the session on the left and the mode in the centre (RAKUMUX MODE, SESSION
  MODE, TERMINAL MODE), with the buttons on the right. A tap on the mode still switches it.

## Fixes

- `Esc` acts at once on a desktop terminal over SSH. It waited up to 800 ms for the rest of an
  arrow key; only phones over SSH, whose keys can arrive in pieces, still wait.

## Upgrading

`U` installs the update and reloads the UI, and the AI status service replaces itself with the new
version. Places and the Enter on its own need the new server: press `S` in Rakumux mode (or run
`rakumux daemon restart`) to restart it in place. Your sessions keep running.
