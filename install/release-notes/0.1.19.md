# Rakumux 0.1.19

## Write back to your agents from the Feed

- Press `r` (or click **↩ Reply**) on a session's newest entry in the Feed to write back to its
  agent. Rakumux types your reply into that session on its machine as soon as the agent waits for
  you, the same way for Claude Code, Codex and OpenCode, and the agent's answer joins it as a
  thread under the entry. Each reply says where it's up to: waiting, typed in, answered, or not
  sent and why. You can reply from rakumux.com/feed too.
- Replies written on rakumux.com or on your other machines are typed into this machine's
  sessions only when you turn on **Settings → Available on sign-in → Replies from rakumux.com**.
  It's off by default, since a reply can make an agent run commands. Replies you write in this
  machine's Rakumux always go in.

## Feed cards

- Each turn in the Feed is a card: the session, then its agent and branch, on the top border,
  and its age and status at the right; inside, your prompt on a bar, then the start of the
  answer.
- A prompt still waiting for its answer shows as a **working** card, which the answer fills in
  when it comes.
- Agents' Markdown is drawn: headings, bold and italics, lists, code, tables and links.

## Sessions and the footer

- A Claude Code agent whose background agents are still running now shows as working, not done.
- When you're signed in, the footer's bottom right says **✓ Signed in** (a click opens the
  account dialog).
- Hovering a session's AI summary shows its ↻ refresh just before it.

## Upgrading

The server changed: after `U` installs the update and reloads the UI, press `S` and then `y` to
restart the server in place, so agents with background agents show as working. Your sessions and
their programs keep running. The AI status service replaces itself with the new version.
