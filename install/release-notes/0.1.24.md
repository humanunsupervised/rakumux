# Rakumux 0.1.24

## Places name their repository

- Each place shows its repository's name before the branch: `focal-md-paper-links  focal-md ⎇
  paper-links`. The name comes from the repository's `origin` remote, else its main checkout's
  folder, read from `.git` files on this machine. A checkout named like its repository doesn't
  repeat it.
- Where a session works now is one line again, in line with the session's name and description:
  its path, then its repository and branch. Short of room the path is cut from its start first,
  then the repository's name, then the branch.
- Its other places (`w`, `W`, or a click on `▸`) sit two columns further in, a divider above each,
  with no bars beside them.

## A tidier list

- Session rows line up with their header: folder, app and status names, `pinned` and every
  session's text start in one column, and the marks (the pin toggle, the summary's ↻, the places'
  `▸`/`▾`, the copy mark) sit in a margin on the left.
- Under Status, ready's `last hour`, `last day` and `older` headers line up with ready instead of
  a step in.
- The working spinner turns faster.

## Help

- The `w`/`W` note says what goes to rakumux.com: with the Agent feed on, places' names, branches
  and times, never full paths.

## Fixes

- The list's ages, on rows and places, come from the list's own clock, the one that sorts ready
  into its periods, so the two always agree.

## Upgrading

`U` installs the update and reloads the UI. The server reads the repository names, so restart it
in place after updating: press `S` in Rakumux mode, then `y` (or run `rakumux daemon restart`).
Your sessions keep running. Places kept from before get their repository's name the next time the
session works there.
