# Rakumux 0.1.12

## Arrow keys switch the list's tabs

- In Rakumux mode, `←`/`→` switch between the list's tabs (Status, Folders, App) wherever the
  selection is, keeping the selected session; `↑`/`↓` go through the sessions.
- `→` no longer goes into a session: `Enter`, `i` or `l` do. Grid keeps its arrows for moving
  between cards.

## Each tab keeps its own order

- Under the Status and App tabs, every status and app has an order of its own: dragging a
  session or `J`/`K` reorders it within its group, across folders, and never into another
  group.
- The Folders tab's order is unchanged by moves there, and each tab's order is its own. They're
  saved in `~/.rakumux/config.json` (`sessions.section_order`); new sessions join the bottom of
  their group, pinned sessions stay first.

## Upgrading

Only the UI changed. `U` (or Settings → Update) installs it and reloads the UI; the server and
running sessions stay up. If you're coming from 0.1.10 or earlier, see the 0.1.11 notes for the
server restart and hook updates.
