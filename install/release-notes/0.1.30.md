# Rakumux 0.1.30

## Restarting the server restarts its services

- `S` (or Settings → Restart server) now restarts the account service and the local API
  (`rakumux-api`, which the phone app and agents' Rakumux tools use) too, on the same build, once
  the server is back. Before, both kept running the version they started with until restarted by
  hand.
- A window started before Rakumux was rebuilt or updated could fail to start the account service
  from its old binary; it now starts the new one.

## Upgrading

`U` installs the update and reloads the UI, and the account service replaces itself with the new
version. The server hasn't changed since 0.1.29, so there's nothing to restart.
