# Rakumux 0.1.28

## Top

- Settings → Top (or `t` in Rakumux mode) shows the machine's CPU, memory and network, then this
  window, the server, the other clients and every live session with its processes as a tree,
  about every second while it's open. Nothing is recorded. Network per process is Linux only;
  macOS shows CPU and memory per process.

## A session's age is its last prompt or reply

- The age beside a session is when its agent last had a prompt or wrote something, by the
  conversation's own clock, kept after the agent exits. Before, it was when you last went into
  the session, and a server that came back after a crash or reboot made every session it revived
  look active then. Sessions without an agent show when they were last used, as before.

## Selecting text stays in its pane

- Drag over a session's preview, a session whose program doesn't use the mouse (a shell, say) or
  the terminal panel to select its text: it stays in that pane and is copied when you let go.
  Shift-drag, your terminal's own selection, ran across the session list. Claude Code uses the
  mouse, so inside its session it still gets the drag: drag over its preview in Rakumux mode
  instead.

## Replies

- A reply that went in while the agent was already working (Claude Code queues it) counts as
  delivered. Before, it could say it wasn't taken although the agent had it.
- A reply written in the feed waits behind ones written a moment before on rakumux.com that this
  machine hasn't read yet, so they go in the order they were written.

## Upgrading

`U` installs the update and reloads the UI, and the account service replaces itself with the new
version. Top, the new session ages and the replies change need the new server: press `S` in
Rakumux mode, then `y` (or run `rakumux daemon restart`) to restart it in place. Your sessions keep
running.
