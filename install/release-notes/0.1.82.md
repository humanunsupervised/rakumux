# Rakumux 0.1.82

## A heartbeat is a command

- **The form is the command that runs.** New heartbeat asks for the name, schedule and folder, then
  the agent, its arguments and the prompt, and shows the command they make: `claude
  --dangerously-skip-permissions -- "Update the dependencies"`.
- **Arguments are suggested.** On the agent or its arguments, the form lists what that agent takes.
  Typing narrows the list and shows an argument's values; `↑` `↓` pick, Tab, Enter or a click takes
  one.
- **Set to run unattended.** Each agent starts with the arguments that stop it asking for
  permission, such as Claude Code's `--dangerously-skip-permissions` and Codex's
  `--dangerously-bypass-approvals-and-sandbox`. An agent run that way does whatever it decides to:
  change them in the form if that's too much.
- **The prompt is an argument.** A run starts its agent with the prompt, so `claude --print`, `codex
  exec` and the like work too. OpenCode, Kimi Code, Amp and Aider still have it typed in once their
  prompt shows. Heartbeats you already have run this way from now on, with the arguments they have.

## Edit a heartbeat

- `c` (or a click on `c edit`) opens the form on a heartbeat: its name, schedule, agent, arguments
  and prompt. `Ctrl-S` or Save keeps what you changed. It was `c rename`; the name is the first
  field.

## Also

- The left column's Beats tab is now called Heartbeats.
