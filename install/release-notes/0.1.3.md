# Rakumux v0.1.3 — native macOS and Linux binaries

Native packages for macOS Intel, macOS Apple Silicon and Linux x64 are built on their
respective GitHub-hosted runners and installed with:

```bash
curl -fsSL https://rakumux.com/install.sh | bash
```

## Changes

- `./release.sh` now selects macOS Intel, macOS ARM64 and Linux x64 by default, regardless of
  which machine starts the release. `--targets` still allows an explicit subset.
- Shell-launched agent scripts are recognized on macOS, preserving Claude conversation IDs,
  model selection and permission flags during session recovery.
- Regression coverage includes interpreter-wrapped scripts, shell-option values, and command
  arguments that must not be mistaken for agent programs.
- Closed macOS sockets preserve buffered terminal exit events and reconnect normally after the
  daemon ends an idle connection.

Every selected target must pass native source checks and isolated package-install verification
before publication. Each archive includes all four native binaries, launchers, `LICENSE` and
`THIRD_PARTY_NOTICES`; the installer verifies its SHA-256 checksum. No npm or Homebrew setup
is required.
