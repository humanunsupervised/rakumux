# Rakumux 0.1.84

## New sessions from the web and the app, with arguments

- **Start an agent with its arguments.** A new session asked for on rakumux.com or in the app can
  carry the agent's arguments, such as `claude --model opus` or `codex --search`, as a heartbeat's
  can. Your machine starts the agent with each one as written: its shell expands nothing in them
  but a leading `~`.
- **Signed like the rest.** The arguments are part of the command your paired device signs, and
  your machine refuses a request whose arguments aren't the ones signed.
- Machines on an older Rakumux keep starting agents without arguments; the web and the app ask you
  to update before sending any.
