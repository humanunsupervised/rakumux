# Rakumux 0.1.46

## Feed cards

- Feed cards are taller (ten rows) and sit a row apart, so more of each reply shows at a glance.
- A card that holds more than it shows has `▾ more` on its bottom border: click it, or press
  Space on the selected card, to see all of it in the feed. `▴ less` (or Space again) puts it
  back.
- A card's header names the session's folder, repository and branch: `claude · web · focal-md ⎇
  main`. The repository is shown for this machine's sessions, and left out when it's named like
  the folder.

## Session list

- The repository's name in a session's places is bold.
