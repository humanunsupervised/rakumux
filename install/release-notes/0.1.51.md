# Rakumux 0.1.51

## Diagnostics

- A crash of the TUI and a lost connection to the server now go to `~/.rakumux/logs/tui.log`, and
  the MCP server's failures to `mcp.log`.
- When rakumux.com asks a signed-in account for diagnostics, the account service sends the
  warnings and errors in Rakumux's log files, masked as the feed is. Only rakumux.com's owner
  accounts are asked. `tui-input.log` is never read.
