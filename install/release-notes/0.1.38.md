# Rakumux 0.1.38

## Answer Claude Code's questions from rakumux.com

- When Claude Code asks you something in its question dialog, its chat on rakumux.com lets you
  answer: pick an option, tick several, type your own answer, or answer several questions at
  once. Rakumux answers the dialog only while that same question is on screen, one key at a time,
  and never a permission prompt. A question you answered in the terminal first is left alone.
- After updating, press `S` so the server can answer; until then the question shows on
  rakumux.com without the option to answer.

## Footer

- The footer shows this Rakumux's version at the far right, when there's room for it.

## Fixes

- After the server restarted in place (`S`, or an update), a session whose agent was waiting
  showed no chat on rakumux.com ("No messages here yet") until you typed in it. It's read at once
  now.
