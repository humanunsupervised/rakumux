# Rakumux 0.1.60

## Heartbeats on rakumux.com and in the app

- Your machine's heartbeats show on rakumux.com and in the mobile app: each one's schedule, folder,
  task and last run. Runs are marked with `♥` in the session list.
- From there you can approve a heartbeat an agent made, after reading it in full, and pause one or
  run it now. Your machine approves only the version you read. If it changed since, it asks you to
  look again.
- The machine has to be signed in (`a` in Rakumux, or `rakumux account login`). The command and
  task are masked like chats are (keys and tokens hidden) before they leave it.
