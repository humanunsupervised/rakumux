# Rakumux 0.1.74

## More secrets masked before they leave your machine

- Chats, replies, agents' latest steps and logs are masked on your machine before they go to
  rakumux.com. The masking now also catches AWS, Slack, Google, Hugging Face, npm, GitLab,
  SendGrid, PlanetScale, Tailscale and several other services' keys, the password in a URL
  such as `postgres://app:…@db`, and variables named for a secret such as `DB_PASS=` or
  `STRIPE_KEY=`.
