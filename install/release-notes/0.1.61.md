# Rakumux 0.1.61

## Heartbeats are approved and run only on your machine

- rakumux.com and the mobile app show your heartbeats and can pause them, but approving, turning
  on and running one now happen only on the machine itself: the Beats tab (`B`) or
  `rakumux heartbeat`. Your machine refuses those from anywhere else, so nobody who can reach
  rakumux.com can have a command run on it.

## Updates only go forward

- An update asked on rakumux.com or in the app installs only a release newer than the one your
  machine runs. An older one is refused before anything is downloaded.
