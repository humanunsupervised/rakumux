# Rakumux 0.1.48

## Session list

- A session's row is now its name, then the repositories it works in, then its app. The
  repositories are in bold and comma-separated, with no folder, worktree or branch.
- `▸` before the repositories, a click on their names, or `w` opens the session's places: where
  it works now first, then everywhere else it changed files. Each place shows its path,
  repository, branch and age.
- The app line names the app alone, as the App tab does. An ended session keeps its agent's
  name.

## Updates

- An update restarts everything in one go. When the UI reloads into an installed update
  (automatically once idle, with `R`, or after `U`), the server, the account service and the
  local API restart with it, in place. Sessions keep running, and you no longer need `S`
  afterwards. This starts with the update after 0.1.48.

## rakumux.com

- The Status page and the feed show what each working agent is doing now: its latest step, as
  its row here shows it.
